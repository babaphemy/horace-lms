## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

## Prettier

- Format all files:

```bash
npm run format
```

- Check formatting:

```bash
npm run lint
```

- Validate code:

```bash
npm run validate
```

- Build for production:

```bash
npm run build
```
